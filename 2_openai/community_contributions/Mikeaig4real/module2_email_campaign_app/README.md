# Module 2 Email Campaign App

This folder now reflects the Week 2 exercise idea: generate multiple email tones, pick the best one, format it, and prepare a send flow.

## Structure
- `sub_agents/serious_sales_agent.py`
- `sub_agents/engaging_sales_agent.py`
- `sub_agents/concise_sales_agent.py`
- `sub_agents/subject_agent.py`
- `sub_agents/html_agent.py`
- `sub_agents/send_agent.py`
- `lead_agent.py` (converged campaign manager agent)
- `manager.py` (executes the converged agent)
- `app.py` (Gradio interface)

## Run
```bash
python 2_openai/community_contributions/Mikeaig4real/module2_email_campaign_app/app.py
```
